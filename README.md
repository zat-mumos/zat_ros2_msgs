# zat_ros2_msgs

This repository contains custom ROS2 messages that is utilized by all other repositories working with ROS nodes. 

## Tested Environment

- ROS2 Humble + Ubuntu 22.04

## Installation and Dependencies

Refer to the README of [zat_launcher](https://git.inf.h-brs.de/zat-rhein-ruhr/zat-prototype-demo/zat_launcher)

## Contents of the Repository

Each folder in this repository contains messages that is utilized by specific repositories.  The details are as follows:
